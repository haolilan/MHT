## MHT 

This repository supports the manuscript titled Heterogeneity in Multisystem Estrogenic and Site-Specific Microbiome Responses to Menopausal Hormone Therapy among Perimenopausal Women by providing the underlying methods and data analysis scripts to ensure reproducibility. As the manuscript is currently under peer review, the dataset provided here is simulated for demonstration purposes. Consequently, the outputs generated by this demo may not perfectly match the final figures in the manuscript. This repository is intended specifically for reviewer evaluation; upon formal publication, the complete dataset will be released and reasults performed by code will be concordance with publication.
